\begin{abstract}
These notes isolate two arguments about selected returns of retarded
semiflows.  For a finite-dimensional fixed-delay \(C^k\) retarded functional
differential equation, a common event window beginning after \(k\) maximum
delays gives a \(C^k\) event time and a \(C^k\) complete-history hit map,
provided a common solution tube, strict endpoint signs, and a uniform
positive event speed are available.  A second result shows that a bounded
positive-time selected return of the same semiflow identifies the local
stable-set germ of a periodic orbit under phase isolation, a common
intervening tube, retained-domain conditions, and recurrent selected hits.
Neither result requires the selected branch to be a first return, and the
second does not require an identity with an iterate of a first-return map.
The threshold \(k\tau_*\) is asserted only as a sufficient condition.  These
notes make no claim of sharpness or independent originality; the comparison
with the full RFDE regularity, Poincar\'e-map, and stable-manifold literature
is an explicit decision gate before any submission-oriented development.
\end{abstract}
