# JNS submission checklist

Checked on 23 August 2026 against the journal’s current aims, scope, and
submission guidelines.

## Manuscript

- [x] English LaTeX manuscript and compiled PDF.
- [x] Brief, descriptive title.
- [x] Running title shorter than 50 characters.
- [x] Abstract states the phenomenon, problem, result, mechanism, and scope.
- [x] Broadly readable introduction with biological and nonlinear-science
      motivation.
- [x] One principal theorem; arbitrary physical outer transfer remains
      conditional.
- [x] General finite-network and three-coordinate control claims are excluded.
- [x] Keywords and 2020 Mathematics Subject Classification included.
- [x] Acknowledgements and AI-assistance disclosure included.
- [x] Funding, competing interests, author contributions, and mandatory data
      availability statements appear before the references.

## Mathematical and computational verification

- [x] Exact algebra, scaling, graph coefficients, and signs have symbolic
      tests.
- [x] Full test suite passes.
- [x] Numerical diagnostic is explicitly separated from the proof.
- [x] Solver tolerances, step refinements, source hashes, and full-precision
      data are recorded.
- [x] Both figures are deterministic, pure-vector PDFs with embedded fonts.
- [x] Complete LaTeX build has no undefined citations/references and no
      overfull or underfull boxes.
- [x] Every PDF page has been rendered and visually inspected.

## Submission package

- [x] Cover letter prepared.
- [x] Three current editorial-board suggestions prepared.
- [x] Main PDF prepared.
- [x] Source and code/data supplementary archives prepared.
- [ ] Confirm editor conflicts immediately before upload.
- [ ] Enter author ORCID and affiliation in the submission system.
- [ ] Upload source archive, main PDF, figures, and code/data supplement.
- [ ] Verify the PDF generated by the journal’s submission system.
- [ ] Release a public persistent archive upon acceptance, as stated in the
      Data Availability section.
