# Paper A: exact fold-time anchored half-line contract

Status: closed mathematical audit contract for the anchored part of Issue
#32 (2026-08-31).  The manuscript statements and proofs are
thm:anchor-annulus-flat-forgetting and lem:anchor-annulus-Green-graphs.
This file records the acceptance gates; it is not itself a theorem.

## 1. Nonnegotiable scope

The construction uses physical fold time

```text
s = delta t
```

throughout.  Hence the voltage delay is exactly `theta_k`, independently of
`delta`, and every delayed term is the literal value `v(s-theta_k)`.

The replacement must contain none of the following:

1. no spatial clock `x=r`, `tau(x)`, or solution-dependent delay foot;
2. no division by a reduced speed near an anchor;
3. no finite terminal section or finite terminal Schur complement on the
   negative side;
4. no assertion that the negative stable sheet is generated by an invariant
   one-dimensional weak-stable tracker;
5. no backward RFDE semiflow.  The only backward operator permitted is the
   inverse on the transported one-dimensional strong-unstable bundle;
6. no second parameter jets.  The half-line theorem supplies `C^1` parameter
   dependence and a `C^1` normalized conormal only.

The positive and negative constructions are deliberately different:

```text
positive side: local W^u(E_+) hit + ordinary forward RFDE IVP;
negative side: [0,infinity) mixed Lyapunov--Perron problem with terminal
               boundedness at infinity.
```

## 2. Fixed phase spaces and literal histories

Let

```text
X_N = C([-theta_m,0]; R^N),
Y_N = X_N x R.
```

The second factor stores the current resource value only; no fictitious
resource history is introduced.  If `Phi` is an original-time voltage
history on `[-theta_m/delta,0]`, its fold-time representative is

```text
(R_delta Phi)(vartheta) = Phi(vartheta/delta),
                         -theta_m <= vartheta <= 0.
```

For a current path `v` on `[-theta_m,infinity)`, write

```text
v_s(vartheta) = v(s+vartheta).
```

The fold-time RFDE is

```text
v'(s) = delta^(-1) F_0(v(s),w(s))
        + delta K sum_k L_k(p) [v(s)-v(s-theta_k)],
w'(s) = delta sigma_anc(r(v_s);p),
r(v_s) = pi_N^T(v(s)-1).
```

Every residual, variational equation, and nonlinear fixed-point map must use
this formula literally.

For weak solutions use

```text
D_-^0 = {
  v in C([-theta_m,infinity);R^N),
  w in C([0,infinity);R),
  (v,w) locally W^{1,infinity} for s>0
}.
```

For differentiable event and conormal statements, recut after three complete
delay buffers and use the compatible `C^3` solution-manifold chart there.
The recut operator and the three seam rows must be displayed.  It is not
enough to say that the original weak path itself has entered a global
`C^3` domain.

## 3. Quantitative anchor data used by both sides

The anchor spectrum theorem must already have supplied, uniformly in `N`,
the structural parameter, and the admitted anchor multiplier:

```text
at E_+ : one slow unstable root, all other roots stable;
at E_- : one strong unstable root, all other roots stable, including one
         slow stable root.
```

In fold time, the relevant rates have the form

```text
slow rate                  >= c_s delta,
strong unstable rate       >= c_u/delta,
capped stable-history rate >= c_h log(1/delta).
```

The corresponding projections, local invariant-manifold charts, and first
parameter derivatives may lose a fixed power `delta^(-M)`, but their bounds
must be independent of `N`.

The local anchor radius may be taken to be a proved polynomial scale such as

```text
rho_A,delta = c_A delta^B,
```

with `B` chosen from the actual Lyapunov--Perron ledger.  No fixed unscaled
local radius is assumed.

## 4. Positive side: exact forward IVP

Choose the inward point

```text
Phi_+^col(p) in W^u(E_+)
```

at the proved local collar section.  Its negative-time extension is supplied
by the local unstable-manifold theorem and converges to `E_+`.

Starting from `Phi_+^col(p)`, solve the raw fold-time RFDE forward.  This is an
ordinary RFDE IVP on `Y_N`; no bordered inverse is used.  The proof must show,
before defining a gap, that the solution

1. remains in the declared positive channel and its depth-three delay hull;
2. reaches the fixed inner event section exactly once;
3. has an event speed bounded away from zero there;
4. depends `C^1` on the admitted parameters after the reserved smoothing
   buffers;
5. continues through the already proved central core to the common Lin
   section.

For the channel estimate, compare the IVP with a declared approximate current
path in physical fold time and use a causal current-path Green estimate.  The
old-history part `s-theta_k<0` and the generated part `s-theta_k>=0` must be
estimated separately.  Event-time differentiation is allowed only at the
fixed inner section where the physical event speed has a common nonzero
bound.

## 5. Negative base orbit: exact chart-center solution

Fix an inner negative entry section `Sigma_-^ent` transverse to the declared
reference passage and lying a fixed distance from the fold and the anchor.
Construct one approximate time-domain seed

```text
Gamma_-(s;p),  0 <= s < infinity,
```

such that

```text
Gamma_-(0;p) lies in Sigma_-^ent,
Gamma_-(s;p) -> E_- as s -> infinity,
```

and whose literal RFDE residual has the weighted smallness required below.
The seed may use a critical-curve formula as a proof device, but it is not a
physical orbit and no theorem may call it one.

Writing `R_Gamma` for that literal residual, the base-orbit gate is

```text
||R_Gamma||_Fbeta + ||partial_p R_Gamma||_Fbeta
  <= c_seed R_delta / ||G_ref||,
```

with `c_seed<1/6`.  The reference Green operator and `R_delta` are defined
below; this inequality, rather than the phrase "small residual", must be
verified from the raw equations.

First solve the mixed half-line problem with zero stable-entry coordinate.
The resulting fixed point is denoted

```text
Zbar_-(s;p),  0 <= s < infinity.
```

It must satisfy the raw anchored RFDE exactly, start on `Sigma_-^ent`, and
converge to `E_-`.  This is the selected chart-center orbit.  It is one exact
orbit chosen by a boundary chart; it is not a weak-stable invariant tracker,
and no family obtained by varying a slow coordinate is asserted to be
invariant.

There are two permissible noncircular implementations:

1. prove a reference half-line dichotomy along `Gamma_-`, solve the zero-entry
   mixed problem, then transfer the dichotomy to the exact `Zbar_-` by
   roughness; or
2. solve the base and its linear graph equations simultaneously in one
   contraction whose diagonal inverse is the explicitly proved reference
   Green operator.

It is not permissible simply to assume an exact center orbit in order to
define the Green operator that is then said to construct that orbit.
In the first implementation the actual base fixed-point equation is

```text
zbar = G_ref[-R_Gamma + N_Gamma(zbar)],
```

with zero stable-entry coordinate and the future unstable integral.  Then
`Zbar_-=Gamma_-+zbar` is exact.

## 6. Exact half-line variational dichotomy

Let `U_-(s,t)` be the variational solution process along the exact
`Zbar_-`.  Prove an invariant splitting

```text
Y_N = X^s_-(s) direct-sum X^u_-(s),
dim X^u_-(s) = 1,
```

with projections bounded by `C delta^(-M)` and with

```text
||U_-(s,t) P^s(t)||
  <= C delta^(-M) exp[-c_s delta (s-t)],       s >= t,

||U_-(s,t) P^u(t)||
  <= C delta^(-M) exp[-A_u(t,s)],              0 <= s <= t,
```

where the second line is only the inverse on the one-dimensional unstable
bundle.  On each fixed negative outer subannulus,

```text
A_u(t,s) >= c_u (t-s)/delta.
```

The stable estimate may use the slow rate `c_s delta`; no false uniform
stable gap is required.  Separately retain the fading-history estimate

```text
kappa_delta = theta_0 log(1/delta)/theta_m
```

when `theta_m>0`, with

```text
||phi||_delta^sharp <= ||phi||_infinity
 <= delta^(-2 theta_0) ||phi||_delta^sharp.
```

The dichotomy proof must be a direct trajectory-space argument.  It must
include:

1. a dimension-uniform nonautonomous current evolution estimate, including
   the stable block and not only moving-frame off-diagonal terms;
2. one whole-half-line Green/Neumann estimate for the delay and chart terms;
3. a direct split between prescribed old history and generated history;
4. reassembly of compatible sliding `C` histories;
5. first parameter derivatives of the projections and Green operators, with
   a displayed polynomial loss.

Pointwise frozen spectral bounds alone do not prove this dichotomy.

## 7. Weighted half-line spaces and mixed Green operator

Choose

```text
0 < beta_delta <= c_s delta/4.
```

Let `||.||_{s,delta}^ph` be the displayed phase/fading history norm along
`Zbar_-`; it must be polynomially equivalent to the ambient `C`-history norm
and make all dichotomy projections polynomially bounded.  Define

```text
||z||_Zbeta
  = sup_{s>=0} exp(beta_delta s)
      ||z_s||_{s,delta}^ph.
```

For a current forcing `f=(f_v,f_w)`, a safe range norm is

```text
||f||_Fbeta
  = sup_{s>=0} exp(beta_delta s) delta^(-1)
      (||f_v(s)||_N + |f_w(s)|).
```

Sharper anisotropic weights may replace this norm, but every component and
its Green cost must then be stated explicitly.

Because a current forcing is not a bounded history vector in the ordinary
`C` phase space, introduce the forced current-path Green kernels

```text
G_-^s(s,t), G_-^u(s,t): R^(N+1) -> Y_N.
```

They are obtained directly from variation of constants and subsequent
sliding-history reassembly; no fictitious bounded injection into `Y_N` is
used.  The mixed Green operator is

```text
(G_- f)(s)
  = integral_0^s G_-^s(s,t) f(t) dt
    - integral_s^infinity G_-^u(s,t) f(t) dt.
```

The second integral uses only the inverse on `X^u_-(t)`.  Prove

```text
||G_- f||_Zbeta <= C delta^(-M_G) ||f||_Fbeta.
```

This infinite integral, not a finite terminal row, enforces terminal
boundedness.  A path in `Zbeta` converges to `E_-`; merely remaining bounded
in an unweighted norm is not enough.

## 8. Stable-entry boundary parameter

At `s=0`, let `ell_ph` define `Sigma_-^ent`.  Project the exact unstable
history into the entry section along the exact time tangent and normalize it
to obtain `j_ent^u`.  Define

```text
K_ent = T_{Zbar_-(0)} Sigma_-^ent intersect X_-^s(0),

T_{Zbar_-(0)} Sigma_-^ent
  = K_ent direct-sum span{j_ent^u}.
```

All intersections, projections, and inverse chart identifications require
common polynomial bounds.  In a fixed compatible solution-manifold chart,
write an entry history as

```text
Phi_ent(psi,u;p)
  = Zbar_-(0;p) + psi + j_ent^u(p) u
    + Q_ent(psi,u;p),

psi in K_ent.
```

Here `Q_ent` is the nonlinear chart correction imposing compatibility and
the entry phase row.

The chart spaces depend on `p`; before parameter differentiation they must be
trivialized to fixed base spaces by explicit graph maps.  Merely saying that
the norms are equivalent is insufficient.

## 9. Nonlinear mixed Lyapunov--Perron graph

Let

```text
N_-(s,z;p)
```

be the exact nonlinear remainder after recentering at the exact `Zbar_-`.
There is no affine residual because the center orbit is exact.  For each
small `psi in K_ent`, solve

```text
z = U_-^s(.,0) psi + G_- N_-(.,z;p),
```

where the entry chart correction is included in the boundary source.  The
unstable entry coefficient is read from the second, future integral and is
denoted

```text
u = F_-(psi;p).
```

The contraction ledger must display a radius `R_delta=c delta^B` satisfying

```text
||G_-|| Lip_z(N_-;R_delta) <= 1/3.
```

The exponent `B` is chosen from the actual fold-time derivative and slow
Green losses.  A claimed `C delta^2` ball is not accepted unless this
inequality is proved component by component.

The fixed point then gives the exact entry stable sheet

```text
S_-^ent(p)
  = { Phi_ent(psi,F_-(psi;p);p) : ||psi|| < R_delta }.
```

The proof must establish both implications:

```text
Phi in S_-^ent  => its forward orbit converges to E_-,

forward orbit in the declared tube converges to E_-
  => Phi belongs to S_-^ent.
```

The reverse implication follows from uniqueness in the weighted mixed
problem, not from a backward semiflow.

State regularity may be `C^2` if needed for the graph theorem.  Parameter
regularity is only `C^1`.  In fixed parameter charts the derivative equation
is

```text
(I-D_z T_{psi,p}) z_p = partial_p T_{psi,p},
```

and its inverse norm is at most `3/2`.  No second parameter derivative is
claimed.

## 10. Normalized conormal

In the fixed entry splitting, the graph has defining row

```text
lambda_ent(p)
  = du - D_psi F_-(0;p),

lambda_ent(p)(j_ent^u(p)) = 1.
```

Prove `C^1` dependence by differentiating the mixed fixed-point equation and
the fixed chart trivializations once.  Equivalently one may solve the dual
half-line integral equation, but no finite terminal pullback denominator is
used.

The required output is

```text
||lambda_ent|| + ||partial_p lambda_ent||
  <= C delta^(-M_lambda).
```

For comparisons, normalize both rows on the same entry column before taking
their difference.

## 11. Finite-core tail replacement and flat forgetting

This comparison is made **inside one fixed anchored RFDE**.  Fix its exact
entry chart, phase row, and splitting

```text
T Sigma_ent = K_ent + span(j_ent^u),
Phi_ent(psi,u;p),             p=(nu,eta).
```

Choose a common negative buffer time `L_delta` before any tail is replaced.
The exact and truncated problems use the same RFDE, the same generated delay
histories, and the same chart on `[0,L_delta]`.  The buffer is chosen so that

```text
c_L/delta <= L_delta <= C_L/delta,
A_u(L_delta,0) >= c_u L_delta/delta,
```

which follows by taking a fixed comparison section strictly between the
entry and anchor collar, where `r'=delta q(r)` and `q` is bounded above and
away from zero.  Hence

```text
A_cap(L_delta,0)
  := min{ A_u(L_delta,0), kappa_delta L_delta }
  >= c log(1/delta)/delta.
```

Here `A_u` is the action of the one-dimensional unstable inverse and
`kappa_delta` is the fading-history cap.  All coefficient differences are
supported in `s >= L_delta`; for a literal finite truncation that support is
represented by its terminal row at `L_delta`.  These post-buffer differences
are only auxiliary realizations of the finite selector.  The intrinsic
half-line object is always that of the one fixed anchored RFDE; this clause
does not compare physical roots of two different global completions.

An **admissible finite-core tail selector** is a scalar `C^2`-in-state,
`C^1`-in-`p` row `b_L` in the common compatible terminal chart such that

```text
|D b_L(j_L^u)| >= c_b delta^(M_b),
||b_L||_{C^2_state,C^1_p} + |D b_L(j_L^u)|^(-1)
  <= C delta^(-M_b),
```

and its selected terminal graph stays in the declared half-line tube.  The
finite-core representative is the solution on `[0,L_delta]` with entry
coordinate `psi` and terminal row `b_L=0`.  The infinite representative is
the restriction of the intrinsic future-asymptotic graph to the same core.
This definition holds the entry stable coordinate, the entry phase, the
entry chart, and the physical coefficients on the whole common core fixed.

Let `Y_infty=(z_infty,u_infty)` and `Y_L=(z_L,u_L)` denote the two mixed
fixed points in the common trivialization, and let `T_infty`, `T_L` be their
fixed-point maps.  Put

```text
A_i = D_Y T_i(Y_i),
b_i,q = partial_q T_i(Y_i),        q in {nu,eta},
B_i = D_psi T_i(Y_i),
A_i,p = D_p[A_i],                  total derivative,
B_i,p = D_p[B_i].
```

The comparison proof must display the following identities, not merely cite
``graph transform``:

```text
Delta Y
 = (I-A_bar)^(-1) [T_infty(Y_L)-T_L(Y_L)],

(I-A_infty) Delta Y_q
 = (b_infty,q-b_L,q) + (A_infty-A_L)Y_L,q,
                                   q in {nu,eta},

(I-A_infty) Delta(D_psi Y)
 = (B_infty-B_L) + (A_infty-A_L)D_psi Y_L,

(I-A_infty) Delta(D_psi Y)_p
 = (B_infty,p-B_L,p)
   +(A_infty,p-A_L,p)D_psi Y_L
   +A_infty,p Delta(D_psi Y)
   +(A_infty-A_L)(D_psi Y_L)_p,
```

where

```text
A_bar = integral_0^1 D_Y T_infty(Y_L+t Delta Y) dt.
```

The first defect and its displayed derivatives consist only of a future
unstable integral from `L_delta` and, in the delayed case, the fading-history
tail.  Applying the entry/inner-trace restriction to these identities and
using the `3/2` inverse bound gives

```text
||F_infty-F_L||
 +||partial_nu(F_infty-F_L)||
 +||D_eta(F_infty-F_L)||
 +||D_psi(F_infty-F_L)||
 +||partial_p D_psi(F_infty-F_L)||
 <= C delta^(-M) exp[-c log(1/delta)/delta].
```

For the conormal, first form the physical rows in the same chart,

```text
ell_i = (du-D_psi F_i) o D Phi_ent^(-1),
a_i   = ell_i(j_ent^u),
lambda_i = a_i^(-1) ell_i.
```

At the intrinsic chart center `a_infty=1`.  The finite row is normalized on
that same fixed entry column; its denominator must be proved
`1+O(f_delta)`, not silently set equal to one.  The normalization is retained
so that transported rows have an unambiguous type.  Its first parameter
derivative is

```text
partial_p lambda_i
 = a_i^(-1) partial_p ell_i
   - a_i^(-2)(partial_p a_i) ell_i,

partial_p a_i
 = (partial_p ell_i)(j_ent^u)
   + ell_i(partial_p j_ent^u).
```

The preceding graph-jet identities then give the same capped-action estimate
for `lambda_infty-lambda_L` and its first `nu` and `eta` derivatives.

On the positive side the comparison class consists of incoming IVPs only
after they have entered one common physical equation.  With `G` the
event-normal causal kernel, `Delta N` the nonlinear source difference, and
`E_ev` the endpoint event correction, its value equation is

```text
Q(s) Delta Z(s)
 = G(s,s0)Q(s0)Delta Z(s0)
   + integral_s0^s G(s,t)Delta N(t)dt + E_ev(s).
```

For `q in {nu,eta}`, the separate differentiated equation is

```text
partial_q[Q(s)Delta Z(s)]
 = (partial_q G)(s,s0)Q(s0)Delta Z(s0)
   + G(s,s0)partial_q[Q(s0)Delta Z(s0)]
   + integral_s0^s [(partial_q G)Delta N
                    +G partial_q Delta N](s,t)dt
   + partial_q E_ev(s).
```

The time tangent is removed only by `E_ev`.  A common attracting buffer of
the displayed capped action gives the same envelope.

The delayed envelope is deliberately

```text
f_delta = C delta^(-M) exp[-c log(1/delta)/delta].
```

The delay-free current estimate may be stronger.  No full-`C` history theorem
uses `exp(-A/delta^2)` when a nonzero long delay is present.

The linear row `lambda_p^ent` in
`thm:oe-family-C1-generator-entry-conormal` is **not** automatically an
admissible representative in this comparison.  It is selected by a finite
terminal physical-speed row on a different pulled core, and that theorem
explicitly does not identify its kernel with a nonlinear stable sheet.  To
use that particular row one would first have to construct its nonlinear
terminal graph on the exact anchored common segment and verify the chart,
support, and unstable-transversality hypotheses above.  Paper A does not need
that extra identification: the exact gap and its conormal are obtained from
the intrinsic half-line sheet and the direct endpoint-tail identity.

## 12. What may be cited and what must be proved

The manuscript may cite standard RFDE results for a single fixed system:

1. local forward well-posedness and uniqueness on `C` histories;
2. the local stable/unstable manifold theorem once the spectral splitting is
   established;
3. eventual smoothing and solution-manifold recutting after a stated number
   of delay buffers;
4. the Banach fixed-point theorem and the ordinary implicit-function theorem;
5. abstract roughness of an exponential dichotomy after all norms and the
   perturbation number have been verified.

The following are paper-specific and cannot be delegated to a citation:

1. dimension-uniform anchor root counts and projection bounds;
2. the polynomial anchor-manifold radius and its first parameter derivative;
3. construction of the approximate negative seed and its weighted residual;
4. construction of the exact selected chart-center orbit;
5. the dimension-uniform nonautonomous half-line dichotomy in the fading
   history norm;
6. the whole-half-line Green/Neumann bound with literal old/generated delay
   histories;
7. the one-dimensional unstable inverse and terminal integral convergence;
8. all `delta` losses in the nonlinear contraction and first parameter
   derivative;
9. entry-chart transversality, channel containment, and physical event-speed
   margins;
10. flat forgetting and the normalized dual/conormal estimate.

## 13. Acceptance gates

The time-domain replacement is closed only if all gates below are explicit in
the manuscript.

- [x] **T0:** the history rescaling is `Phi(vartheta/delta)` and every delay is
  literal `v(s-theta_k)`;
- [x] **T1:** the positive object is an exact forward IVP from the local
  `W^u(E_+)` hit;
- [x] **T2:** the negative approximate seed, its residual, and its reference
  Green inverse are defined without assuming an exact orbit;
- [x] **T3:** the zero-entry mixed problem constructs one exact chart-center
  orbit converging to `E_-`;
- [x] **T4:** the dichotomy is transferred to that exact orbit and has uniform
  half-line Green bounds;
- [x] **T5:** the entry splitting `K_ent + span(j_ent^u)` and all fixed parameter
  trivializations are defined;
- [x] **T6:** the infinite mixed integral constructs `u=F_-(psi;p)` and proves
  both directions of stable-set membership;
- [x] **T7:** the nonlinear contraction radius and every polynomial `delta` loss
  are displayed;
- [x] **T8:** only first parameter derivatives and a `C^1` normalized conormal
  are claimed;
- [x] **T9:** positive and negative channel containment are proved before the
  central membership gap is evaluated;
- [x] **T10:** finite-core tail replacement is derived from the time-domain Green
  formulas for the precisely declared common-core comparison class, including
  value, first-parameter, state-derivative, and normalized-conormal difference
  equations.  No linear finite-terminal row is identified with the nonlinear
  stable sheet without separately verifying that it belongs to this class.

Failure of any of T0--T10 leaves the physical half-line theorem open.
