# Quadratic collective defect in a finite balanced network

Status: **proved conditionally on the same voltage-strip residence used by
the nonlinear synchronization theorem, uniformly in finite network size and
admitted topology.**  The theorem identifies the exact forcing by which the
network mean differs from the scalar leaky RFDE and proves that this forcing
is quadratic and integrable.  It does not yet construct a scalar shadowing
tube, an invariant strip, an asynchronous pulse threshold, or basin routing.

## 1. Exact mean equation

Normalize \(\pi^T\mathbf1=1\) and put

\[
 \bar v=\pi^Tv,\qquad \bar w=\pi^Tw,
 \qquad f(s)=s-s^3/3,\qquad H(s)=(s-1)^3.
\]

The balance identities for \(Q,B_0,B_1\) make every network-linear term
close exactly on \((\bar v,\bar w)\).  Therefore

\[
\begin{aligned}
 \bar v'={}&f(\bar v)-\bar w
 +\varepsilon\kappa_1
 \left\{\frac{\bar v_{\tau_0}+\bar v_{\tau_1}}2-\bar v\right\}\\
 &+\varepsilon\kappa_3
 \left\{\frac{H(\bar v_{\tau_0})+H(\bar v_{\tau_1})}2-H(\bar v)\right\}
 +R_{\rm coll},\\
 \bar w'={}&\varepsilon(\bar v-a-\bar w),
\end{aligned}                                                    \tag{1.1}
\]

where

\[
\begin{aligned}
R_{\rm coll}={}&\pi^Tf(v)-f(\bar v)\\
&+\varepsilon\kappa_3\left\{
 \frac{\pi^TH(v_{\tau_0})-H(\bar v_{\tau_0})}{2}
 +\frac{\pi^TH(v_{\tau_1})-H(\bar v_{\tau_1})}{2}
 -\bigl[\pi^TH(v)-H(\bar v)\bigr]\right\}.
                                                               \tag{1.2}
\end{aligned}
\]

Thus the mean is the scalar RFDE with one explicit additive voltage forcing;
there is no recovery defect.

## 2. Exact quadratic bound

For any probability vector \(\pi\), twice differentiable scalar map \(g\),
and real vector \(x\), Taylor expansion at \(\bar x=\pi^Tx\) gives

\[
 \left|\pi^Tg(x)-g(\bar x)\right|
 \le \frac12\sup|g''|\,\operatorname{osc}(x)^2.        \tag{2.1}
\]

The first-order term cancels exactly because
\(\pi^T(x-\bar x\mathbf1)=0\).  On \(|v_i-1|\le5/2\),

\[
 \sup|f''|\le7,
 \qquad \sup|H''|\le15.                                \tag{2.2}
\]

Using \(\varepsilon=1/5\) and \(\kappa_3=1/200\), equations
(2.1)--(2.2) give the time-resolved bound

\[
 |R_{\rm coll}(t)|
 \le \frac{1403}{400}M(t)^2
 +\frac3{800}\left\{M(t-\tau_0)^2+M(t-\tau_1)^2\right\}. \tag{2.3}
\]

In particular, for the retained-history envelope

\[
 \mathcal H_M(t)=\sup_{t-r\le s\le t}M(s),
\]

equation (2.3) implies

\[
 |R_{\rm coll}(t)|\le\frac{703}{200}\mathcal H_M(t)^2. \tag{2.4}
\]

The delayed values in (2.3) cannot be replaced by the current \(M(t)\).
For example, the current diameter may vanish at \(t_0\) while a retained
delayed history still has nonzero diameter.  No \(\pi_{\min}^{-1}\),
Euclidean norm equivalence, node count, or topology constant enters
(2.3)--(2.4).

## 3. Integrable forcing

Put

\[
 M_0=\sup_{t_0-r\le s\le t_0}M(s).
\]

The parent nonlinear theorem proves, while the retained solution remains in
the strip,

\[
 M(t)\le M_0e^{-(t-t_0)/10}.
\]

The current term in (2.3) therefore integrates with factor \(5\).  For a
delayed term, the interval \([t_0,t_0+\tau_j]\) still reads the prescribed
initial history and contributes at most \(\tau_jM_0^2\); after that time a
change of variables gives the same factor \(5\).  Hence, with
\((\tau_0,\tau_1)=(4\sqrt5,5\sqrt5)\),

\[
 \int_{t_0}^{\infty}|R_{\rm coll}(t)|\,dt
 \le\left(\frac{703}{40}+\frac{27\sqrt5}{800}\right)M_0^2
 \le\frac{56483}{3200}M_0^2.                          \tag{3.1}
\]

The term \(27\sqrt5/800\) is the exact initial-history residence correction.
The exact algebraic coefficient in (3.1) is strictly smaller than
\(56483/3200\); the displayed bound uses a non-strict inequality so it also
includes \(M_0=0\).
Omitting it is equivalent to assuming exponential decay before the declared
initial time and is not valid for an arbitrary retained history.

This is the missing quantitative input for a future scalar routing-tube
argument: asynchronous network motion drives the collective scalar channel
only by a uniformly integrable quadratic defect.  A separate robustness
theorem for the scalar separator and its two basin routes is still required
before (3.1) can be promoted to a topology-uniform asynchronous onset result.
