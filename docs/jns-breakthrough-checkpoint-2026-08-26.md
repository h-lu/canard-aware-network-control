### General selected-return theory

Let \(X=C([-\tau_*,0],\mathbb R^d)\), with finite \(d\). For a fixed-delay
\(C^k\) RFDE, a \(C^k\) initial-section chart, an open \(C^k\)
section-functional domain, and a common solution/event tube, suppose the
selected event window satisfies

\[
T_->k\tau_*,
\]

strict endpoint signs, and uniformly positive event speed. Then the event
time and ambient event-hit map are \(C^k\); when the image returns to the same
section chart, the induced section map is \(C^k\). The inequality is a safe
sufficient condition, not a sharpness claim. Its qualitative form is
independent of finite network size. No no-earlier-hit premise is needed for
smoothness of the selected branch.

A bounded positive-time selected return of the same semiflow, with an
invariant phase-isolating section patch, a common intervening tube, and
recurrent selected hits on stable flow orbits, identifies the intrinsic
periodic-orbit stable-set germ. Proving \(Q=P^m\) is sufficient but not
necessary.
