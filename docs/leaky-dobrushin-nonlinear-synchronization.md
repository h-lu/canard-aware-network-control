# Nonlinear synchronization in the balanced finite-network voltage strip

Status: **proved conditionally on strip residence, uniformly for every finite
network in the declared balanced Dobrushin class.**  This strengthens the
linear transverse theorem to a nonlinear node-diameter estimate.  It does
not prove that the strip is forward invariant, and therefore does not by
itself supply a topology-uniform basin, an asynchronous canard connection,
or a physical onset theorem.

## 1. Network class and oscillation norm

Use the finite network and balance assumptions

\[
 Q\mathbf1=\mathbf1,
 \quad \pi^TQ=\pi^T,
 \quad \tau(Q)\le\frac12,
\]

and, for \(j=0,1\),

\[
 B_j\ge0,
 \quad B_j\mathbf1=\frac12\mathbf1,
 \quad \pi^TB_j=\frac12\pi^T.
\]

For a real node vector put

\[
 \operatorname{osc}z=\max_i z_i-\min_i z_i,
 \qquad
 M(t)=\max\{\operatorname{osc}v(t),
                    3\operatorname{osc}w(t)\}.          \tag{1.1}
\]

Consider any classical network solution on an interval whose retained past
satisfies

\[
 |v_i(s)-1|\le\frac52                                  \tag{1.2}
\]

for every node and every required delayed time.  No closeness to a named
periodic orbit is assumed.

## 2. Exact nonlinear inequalities

Combine the instantaneous scalar terms into

\[
 F(s)=s-\frac{s^3}{3}-\varepsilon\kappa_1s
      -\varepsilon\kappa_3(s-1)^3.
\]

For all real \(s\),

\[
 F'(s)=1-s^2-\varepsilon\kappa_1
       -3\varepsilon\kappa_3(s-1)^2
 \le1-\varepsilon\kappa_1=0.9992.                     \tag{2.1}
\]

Thus (2.1) is a global one-sided Lipschitz estimate; no absolute derivative
bound is used.  Also, with \(H(s)=(s-1)^3\),

\[
 -(H(p)-H(q))(p-q)\le0                                \tag{2.2}
\]

for all real \(p,q\).  Hence the current \(-H(v)\) term is dissipative at an
oscillation-realizing pair.  On (1.2),

\[
 |H'(s)|=3|s-1|^2\le\frac{75}{4}=18.75.                \tag{2.3}
\]

The half-mass Dobrushin estimate consequently bounds the sum of both delayed
voltage slots by

\[
 \beta\sup_{t-5\sqrt5\le s\le t}M(s),
 \qquad
 \beta=\varepsilon\left(\kappa_1+\frac{75}{4}\kappa_3\right)
       =0.01955.                                        \tag{2.4}
\]

For a maximizing node \(i\) and minimizing node \(k\), the stochastic
coupling satisfies

\[
 (Qv)_i-(Qv)_k\le\tau(Q)\operatorname{osc}v.           \tag{2.5}
\]

Equations (2.1)--(2.5), together with
\(|w_i-w_k|\le M/3\), give exactly the voltage row of the parent Halanay
estimate.  The recovery equation is affine, and at a recovery maximum it
gives

\[
 D^+[3\operatorname{osc}w]
 \le-\{2(1-\tau(Q))+\varepsilon-3\varepsilon\}M
 \le-0.6M.                                             \tag{2.6}
\]

Taking the upper Dini derivative of the maximum in (1.1) therefore yields

\[
 D^+M(t)\le-\alpha M(t)
 +\beta\sup_{t-5\sqrt5\le s\le t}M(s),                 \tag{2.7}
\]

with the same directed \(\alpha,\beta\) as the validated linear theorem.

## 3. Uniform nonlinear conclusion

The parent directed arithmetic proves

\[
 \alpha-\frac1{10}-\beta e^{\sqrt5/2}
 >0.0076664505356400.                                  \tag{3.1}
\]

A first-crossing Halanay argument applied directly to (2.7) gives:

> **Theorem 3.1 (stripwise nonlinear synchronization).**  For every finite
> admitted balanced topology and every real classical solution satisfying
> (1.2),
> \[
> M(t)\le e^{-(t-t_0)/10}
>       \sup_{t_0-5\sqrt5\le s\le t_0}M(s),
> \qquad t\ge t_0,                                     \tag{3.2}
> \]
> for as long as the retained solution remains in the strip.  The constant
> one and rate \(1/10\) are independent of the number of nodes and of the
> admitted topology.

This is a nonlinear theorem: (3.2) compares nodes of the same nonlinear
network solution, not solutions of a variational equation.  It shows that
no nonlinear transverse pattern can persist while the solution remains in
the declared strip.

## 4. Exact boundary of the result

The theorem does not control the collective component.  In particular,
small node diameter does not prevent every node from leaving the strip
together.  Therefore (3.2) alone does not prove:

- forward invariance of (1.2);
- a topology-uniform nonlinear basin radius around the quiet state or either
  periodic orbit;
- persistence of a canard connection under heterogeneous node parameters;
- an asynchronous physical pulse threshold.

For exact synchronous histories and pulses, the scalar dynamics lift
identically.  For asynchronous robustness, Theorem 3.1 must be combined
with a collective scalar tube or a phase--amplitude chart that keeps the
whole network inside (1.2).  This separates the now-proved nonlinear
synchronization mechanism from the still-open invariant-tube problem.
